# Orespawn Reborn

Orespawn Reborn es un addon RPG personalizado
para Minecraft Bedrock Edition.

## Características

- Sistema de niveles y experiencia.
- Atributos y habilidades individuales.
- Progresión persistente por jugador.
- Sistema de fabricación personalizado.
- Estaciones de fabricación.
- Nuevos minerales, armas y armaduras.
- Jefes, mazmorras y dimensiones.
- Compatibilidad multijugador cooperativa.

## Tecnologías

- JavaScript
- JSON
- Minecraft Bedrock Script API
- Git
- GitHub

## Estructura

- Orespawn_BP: comportamiento y sistemas.
- Orespawn_RP: modelos, texturas y recursos.
